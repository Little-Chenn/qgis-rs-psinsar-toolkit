# 0.3.0-rc1 中英双语预发布候选版说明

[English](RELEASE_NOTES.md) | **简体中文**

## 版本定位

`0.3.0-rc1` 在独立开源准备仓库中，将本地资格验证通过的
`0.3.0-dev.8-bilingual-rc3` 提升为规范的公开候选版本名称。本次操作不覆盖
`0.2.3` 正式基线、dev.6 中文候选、已验证的 dev.8 源码或 RC3 ZIP。

本次提升加入已确认的许可证、版权、作者单位、公开邮箱和候选版本号，不计划修改
科学算法、数值、机器字段、公式或已人工验收的专题图模板。

## 国际化与界面

- Qt `.ts/.qm` 翻译目录随 QGIS 界面语言加载；
- 任务中心、六模块界面、校验、进度、日志、错误和人类可读报告支持中英文；
- SAR 强度 dB、垂直形变速率和累计形变专题图具有独立英文 QPT；
- 已验收英文专题图的可见英文统一使用 Times New Roman；
- 模块1、2可缩放，并使用适合较小屏幕的紧凑滚动布局；
- 输出目录、文件名、数据字段、JSON 键、公式、选择模式和机器状态保持不变。

## 科学口径

- GCP 模块属于外部 GCP 影像到地图坐标的几何校正，不属于
  Range-Doppler 地形校正；
- 缺少完整 Sigma0/Gamma0 定标证据时，只使用 `SAR intensity (dB)`；
- 垂直形变速率单位为 `mm/year`，正值向上、负值向下；
- 累计形变量单位为 `mm`，固定先逐点计算 `D_target - D_initial`，再对
  50 m 网格内有效差值取中位数；存储数值不进行缩放；
- 多点时序仅用于描述性人工回查，不自动识别异常、趋势类型或物理成因；
- Float32 科学栅格与8位显示产品继续分离。

## 验证状态

源码基线和内部 RC3 已通过 QGIS 3.44.11 全新原生 ZIP 安装、39 项自动测试、
英文六模块界面检查、中英文六模块轻量回归、双语数值比较、三类专题图回归及作者
人工验收。正式本地 RC1 ZIP 随后也已通过中英文全新配置原生安装、七窗口界面
检查、安装副本 39/39 自动测试及三类专题图数值与模板回归。

创建公开 Release 或提交 QGIS 插件仓库。所有外部发布操作仍需另行取得明确授权。

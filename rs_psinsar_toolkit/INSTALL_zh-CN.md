# 0.3.0-rc1 双语预发布版安装与短验收说明

[English](INSTALL.md) | **简体中文**

## 安装

从 [GitHub Releases](https://github.com/Little-Chenn/qgis-rs-psinsar-toolkit/releases/tag/v0.3.0-rc1)
下载 `rs_psinsar_toolkit-0.3.0-rc1.zip`。首次试用建议采用独立 QGIS 配置，
便于保留原有插件安装和设置。

1. 在 QGIS 中打开“插件”→“管理并安装插件”。
2. 选择“从 ZIP 安装”。
3. 选择下载的 `rs_psinsar_toolkit-0.3.0-rc1.zip`。
4. 如提示同名插件已安装，仅在预定测试配置中确认升级。
5. 从插件菜单或工具栏打开“遥感影像与 PS-InSAR 处理制图工具箱”。

## 界面短验收

主工具箱应显示两列三行共六个入口：

1. GCP 几何校正与精度检查；
2. SAR 影像镶嵌、裁剪与显示增强；
3. SAR 强度 dB 专题制图；
4. PS-InSAR 垂直形变速率专题制图；
5. PS-InSAR 累计形变批量制图；
6. PS-InSAR 多点形变时序回查。

检查六个窗口标题不含候选版本号或内部引擎号，模块说明完整位于卡片边框内，
所有关闭按钮显示“关闭”。SAR 影像处理页应可滚动，参数标签紧邻对应输入框，
六个确认项为三行两列。

## 功能短验收

- GCP 模块：分别打开“GCP 几何校正”和“流程验证”，检查顶部说明及字段名称；
- SAR 影像处理：扫描单景 ORG，检查显示参数和科学确认项联动；
- SAR 强度 dB 专题图：读取 dB 影像信息，检查右侧说明预览和导出设置；
- 垂直形变速率专题图：检查面状网格、字段、底图及制图信息；
- 累计形变批量制图：扫描时相，检查 D₀/Dₜ 说明、日期列表和初始时相选项；
- 多点形变时序回查：分别检查既定点位清单和完整候选表，确认抽样参数联动。

每次执行都应在用户选择的输出根目录下创建新的时间戳子目录，且不修改输入数据。
当前完整验证环境为 QGIS 3.44.11。

## 语言检查

插件语言默认跟随 QGIS 界面语言。分别使用 `zh_CN` 和英文界面启动 QGIS，
确认任务中心、六模块、日志、错误提示、报告和内置专题图模板随语言切换。
输出目录名、文件名、JSON 键、数据字段、状态值和计算结果不随语言改变。

## 验证状态

本地 RC1 ZIP 已通过 QGIS 3.44.11 中英文全新配置原生安装、七窗口界面检查、
安装副本 39/39 自动测试及三类专题图数值与模板回归。此前双语 RC3 也已通过
作者人工六模块和三图验收。上述验证范围为所用环境和参考数据；用于科研或
实际业务前，请使用自己的输入数据检查各流程的输出。

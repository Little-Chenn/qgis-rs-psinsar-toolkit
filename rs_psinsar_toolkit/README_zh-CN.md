# 遥感影像与 PS-InSAR 处理制图工具箱

[English](README.md) | **简体中文**

- 插件 ID：`rs_psinsar_toolkit`
- 候选版本：`0.3.0-rc1`
- 作者：杨晨曦（Yang Chenxi）
- 作者所属机构：中国海洋大学（Ocean University of China）
- 项目开展地点：厦门大学联合遥感接收站（Xiamen University Joint Remote
  Sensing Receiving Station）
- 公开邮箱：cyang5533@gmail.com
- 状态：实验性中英双语预发布候选，已在 GitHub Releases 提供下载

本插件集成 GCP 几何校正、SAR 强度处理与制图，以及已有 PS-InSAR 成果的
专题制图和描述性时序回查。PS-InSAR 输入须满足所需结构、单位和垂直形变约定；
本插件不执行从 SAR 影像估计形变或将视线向形变转换为垂直形变的计算。

## 当前能力

- 主任务中心；
- PS-InSAR 专题制图；产品版本保留在插件管理器、
  日志和质量检查报告中，不显示在主窗口标题中；
- GCP 几何校正与精度检查：
  - 使用外部训练GCP执行一阶仿射、二阶/三阶多项式或薄板样条校正；
  - 独立导入检查点，分别输出训练残差和独立检查RMSE；
  - 支持标准CSV及QGIS Georeferencer的`.points`字段；
  - 可设置目标CRS、自动/指定分辨率、重采样和可选RMSE阈值；
  - 输出校正GeoTIFF、控制点副本、残差表、QA预览和JSON/Markdown报告；
  - 完成后可加载成果并自动缩放到图层；
  - 流程验证保留为第二页签，用于验证控制点、RMSE 和报告链路；
  - 不宣称执行SAR轨道、传感器模型或DEM地形校正。
- SAR栅格处理：
  - 递归扫描ORG产品目录，读取XML、`manifest.safe`和KML伴随元数据；
  - 扫描后可一键仅保留升轨、仅保留降轨或恢复全部，不改源文件；
  - 支持单景或多景单波段GeoTIFF及同CRS Polygon/MultiPolygon预检；
  - 默认阻止升降轨混用与超过6 dB的组内强度尺度异常，用户明确确认后才可继续；
  - 识别无声明NoData的NaN边缘，使用只读临时VRT保护镶嵌接缝；
  - 按裁剪面交集估算实际处理像元、内存和磁盘规模；
  - 线性功率默认使用最近邻；三次卷积需显式风险确认；
  - 精确记录dB前有限、负值和零值线性像元数；
  - GUI中明确显示并调整影像覆盖顺序；
  - 统一目标网格后镶嵌；
  - 按矢量掩膜裁剪；
  - 线性功率执行`10*log10`转dB；
  - 支持累计百分比、最小—最大、均值—标准差、直方图均衡和均值居中归一化；
  - 支持亮度、对比度和 Gamma 等亮度与层次调整，以及灰度与单波段伪彩色；
  - 可生成独立RGBA 8位显示产品及默认关闭的基础外缘羽化；
  - 输入SHA-256前后核验；
  - 中文编号成果目录和根目录成果说明；
  - 独立任务目录拒绝覆盖，失败和取消具有终态记录；
  - QGIS后台任务、进度和协作取消；
  - 完成后可选择加载dB结果，不清空现有图层。
  - 加载时把图层范围转换到当前工程坐标系后自动缩放；
  - 使用32—224柔和灰度，避免最大值与白色画布融为一体；
  - 图层名加入run标识，便于区分重复运行。
- SAR 强度 dB 专题制图：
  - 直接读取单波段dB GeoTIFF，不重复镶嵌、裁剪或10log10处理；
  - 使用内置 A3 竖版 QPT 模板；
  - 输出可继续人工微调的QGZ、PNG、PDF及QA报告；
  - 坐标参考系、空间分辨率、显示方法、数据来源、数据拍摄时间、
    制图时间和制作单位均可独立显示或隐藏；
  - 色标为可独立移动和编辑的灰度条、最大值与最小值标签；
  - 不显示QGIS自动生成的波段标题，色标数值统一保留两位小数；
  - 右侧三项按中英文实际宽度自动换行，隐藏后不保留空白占位行；
  - GUI实时预览右侧排版，超过8行时阻止导出，避免越出页面；
  - 从输入栅格自动读取坐标参考系与像元分辨率，仍允许用户修改；
  - 使用2%—98%显示分位数和黑—白灰度，显示参数不修改dB像元值；
  - 每次生成新的便携式run，复制dB栅格并核对输入前后SHA-256。
- PS-InSAR累计形变量批量制图：
  - 输入PS-InSAR多时相GeoPackage并只读扫描`time_catalog`；
  - 默认选择全部后续时相，初始时相图默认不输出；
  - 先逐点计算`D_target - D_initial`，再按50米网格取中位数；
  - 形变量单位固定为mm，正值表示垂直向上，负值表示垂直向下；
  - 所有时相统一使用以 −20 mm 和 20 mm 为外侧分级边界的色标，便于横向比较；
  - 使用人工确认模板的版式等价便携副本，仅清除旧原型图层绝对路径；
  - 输出一个含多布局的可编辑QGZ、逐时相PNG/PDF和QA报告；
  - 不创建、不显示极端点图层；
  - 使用宽表网格结果避免为每个时相重复保存相同几何；
  - 支持合作式取消；取消任务保留状态和临时文件，重新执行创建新的任务目录。
- PS-InSAR 多点形变时序回查：
  - 直接只读查询符合插件结构的多时相GeoPackage，无需加载全量点图层；
  - 点位CSV至少包含`ps_uid`；已排序清单按原顺序回查；
  - 完整候选表默认按A/B×LOW/HIGH各12点及500米全局间距受控抽样；
  - C类极端候选保留在输入中，但不进入默认48点样本；
  - 输出时序长表、点位摘要、可编辑点位GeoPackage、总览PNG、明细PDF和QA报告；
    时相数量取决于输入数据，参考验证数据包含 56 期；
  - displacement单位固定为mm，正值向上、负值向下；
  - 仅输出描述性证据，不自动判定异常或物理成因；
  - 每次创建新的时间戳子目录，支持合作式取消且不修改输入。

## SAR处理科学约束

SAR栅格处理只接受单波段、非负、线性功率栅格。用户必须逐次确认：

1. 输入确实是线性功率值，可以执行`10*log10`；
2. 多景时当前影像顺序正确，后输入影像的有效像元覆盖先输入影像；
3. 只有确有科学理由时才确认升降轨混用或强度尺度异常。

源影像与裁剪面必须使用同一CRS。当前版本不自动重投影裁剪面，不做
自动seamline或物理辐射平衡。显示增强写入独立8位产品，不修改Float32
科学像元值；基础外缘羽化不代表自动无缝拼接。未发现Sigma0/Gamma0等定标证据时，成果元数据和波段描述使用
`SAR intensity (dB)`，不把它误称为定标后向散射。SAR专题图模块只消费
已有dB成果，不改变SAR处理结果。

插件不会修改源栅格或裁剪面。所有输出写入新的run；失败或取消run保留
状态记录，但不作为正式成果。

## 当前暂缓或未集成

- SAR轨道/传感器模型/DEM地形校正：应由SNAP等专业流程承担；
- 多波段真彩色、假彩色组合及物理辐射平衡；
- 16分区图集：当前不进入主线；
- 已取消任务的断点续算：当前采用重新创建任务目录，不在原目录中继续。

`0.3.0-rc1` 为实验性中英双语预发布候选，安装包可从
[GitHub Releases](https://github.com/Little-Chenn/qgis-rs-psinsar-toolkit/releases/tag/v0.3.0-rc1)
下载。运行模板不携带本机工作区绝对路径。
安装包已在 QGIS 3.44.11 中英文全新配置中完成 ZIP 安装、任务中心及六模块
界面检查，每种语言下均通过 39 项自动测试，并完成三类专题图的数值与模板回归。
上述验证范围为所用环境和参考数据，使用自己的数据时仍需检查输出是否符合要求。

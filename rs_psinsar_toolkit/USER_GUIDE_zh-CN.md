# 用户操作手册

[English](USER_GUIDE.md) | **简体中文**

## 1. 主任务中心

从QGIS插件菜单或工具栏打开“遥感影像与 PS-InSAR 处理制图工具箱”。包含：

1. GCP 几何校正与精度检查；
2. SAR 影像镶嵌、裁剪与显示增强；
3. SAR 强度 dB 专题制图；
4. PS-InSAR专题制图；
5. PS-InSAR累计形变量批量制图；
6. PS-InSAR 多点形变时序回查。

## 2. 通用安全规则

- 先选择已存在的输出根目录，插件会在其中创建新的时间戳子目录；
- 插件不会删除、移动或覆盖源数据及历史成果；
- 失败或取消的run仅用于诊断，不作为正式成果；
- 输出QGZ可以在QGIS布局中继续人工微调；
- 科学数值和显示拉伸是两件事，改变颜色或分位数不会修改像元值。

## 3. SAR 强度 dB 专题制图

输入必须是已经确认单位为dB的单波段GeoTIFF。模块不会再次执行镶嵌、
裁剪或`10log10`。

1. 选择dB GeoTIFF和输出根目录；
2. 点击“读取影像信息”；
3. 设置标题和7项可选文字；
4. 在右侧预览中检查自动换行，最多允许8行；
5. 选择QGZ、PNG、PDF及DPI；
6. 检查设置后生成。

输出包含便携式dB副本、可编辑QGZ、PNG、PDF和QA报告。灰度色标没有自动
波段标题，上下限保留两位小数，数字字号为24 pt。

## 4. GCP 几何校正与精度检查

默认打开“GCP 几何校正”页。该页使用外部训练 GCP 执行影像到地图校正，
支持一阶仿射、二阶/三阶多项式和薄板样条，并使用另一份互相独立的
检查点计算RMSE。

1. 选择待校正栅格；
2. 选择训练GCP和独立检查点文件；
3. 输入目标CRS，例如`EPSG:32650`；
4. 选择变换模型；二阶、三阶和TPS需要更多且分布均匀的训练GCP；
5. 输出分辨率保持“自动”，或同时填写X/Y；
6. 根据数据类型选择重采样；
7. RMSE阈值为0时只报告并等待人工判断；
8. 阅读科学边界并勾选确认；
9. 检查设置后运行。

标准CSV表头为`point_id,pixel,line,x,y`，其中pixel/line以左上角为原点，
line向下为正。也支持QGIS Georeferencer的`.points`字段；当`sourceY`
全部为负数时会自动转换为GDAL正向line坐标。

输出包括`01_控制点`、`02_校正成果`、`03_质量检查`和`04_报告`。
只有检查点确实独立于训练GCP且来自可靠外部参考时，独立RMSE才有科学意义。

“流程验证”页保留原流程：影像转 PNG—自动派生训练 GCP/检查点—恢复
GeoTIFF—RMSE与对比报告。它只验证软件链路，不代表真实人工配准精度。

本模块不读取SAR轨道、传感器模型或DEM，不可替代SNAP等软件的严格SAR
Range-Doppler地形校正。

## 5. SAR 影像镶嵌、裁剪与显示增强

输入必须是单波段、非负、线性功率GeoTIFF，裁剪面必须是与影像同CRS的
Polygon/MultiPolygon。可直接选择老师提供的ORG总目录，插件会递归识别
产品文件夹中的TIFF、XML、`manifest.safe`和KML；也支持单景处理。

1. 扫描影像并明确调整覆盖顺序；
   ORG总目录含多种轨向时，可点击“仅保留升轨”或“仅保留降轨”；
2. 选择裁剪面和输出根目录；
3. 设置分辨率和重采样；线性功率推荐保持“最近邻”；
4. 选择显示增强方法、亮度与层次调整参数（亮度、对比度、Gamma），
   以及灰度/单波段伪彩色；
5. 如需独立8位显示产品，保持对应复选框开启；基础外缘羽化默认为关闭；
6. 逐次确认线性功率语义；多景时确认覆盖顺序；
7. 如检测到升降轨混用或组内强度中位数偏离超过6 dB，先核对产品，
   只有确需混用/保留时才勾选相应科学风险确认；
8. 查看掩膜范围资源估算后运行。

处理顺序为统一网格、镶嵌、裁剪、`10*log10`转dB，再按需生成独立8位
显示产品。当前不做自动seamline或物理辐射平衡；基础外缘羽化仅影响
显示产品。下拉框中的“三次卷积”保持简洁显示，但它可能产生
非物理负功率，只有明确需要并勾选其独立风险确认后才允许运行；
报告会精确记录负值数量。无声明NoData的NaN边缘会通过只读临时VRT转换为透明
空值，避免后景NaN遮盖先景有效像元。若元数据没有定标证据，输出标记为
`SAR intensity (dB)`，而不是calibrated backscatter。

单波段VV按数值着色称为“单波段伪彩色”，颜色不代表地物真实颜色。
所有显示增强均不改变Float32线性功率或dB科学成果。

## 6. PS-InSAR专题制图

输入为含velocity数值字段的面状GeoPackage图层，也可使用当前工程中的
已加载图层。底图可选择本地栅格、当前工程图层或无底图。

已确认语义：velocity单位为mm/年，正值表示垂直向上，负值表示垂直向下；
displacement单位为mm。使用其他来源数据时仍应自行核对其单位和方向。

## 7. PS-InSAR累计形变量批量制图

输入应为符合项目数据结构的PS-InSAR多时相GeoPackage，其中包含`ps_timeseries_points`和
`time_catalog`。插件不会修改该文件。

1. 选择多时相GeoPackage，点击“只读扫描时相”；
2. 默认已选择全部后续时相；如需零值基准图，可额外勾选D0图；
3. 选择本地卫星底图和已存在的输出根目录；
4. 模板留空时使用插件内置的人工确认模板，也可以选择兼容QPT；
5. 设置标题、数据来源、监测时段、制图时间和制作单位；
6. 选择QGZ、PNG、PDF及DPI，检查设置后运行。

计算顺序固定为：逐点计算`D_target - D_initial`，再对每个50米网格中的
差值取中位数。单位为mm，正值向上、负值向下；所有时相使用统一正负20 mm
分级色标。当前版本不创建极端点图层。

输出任务目录包含：

- `data/cumulative_displacement_grid.gpkg`：共享几何的多时相宽表网格；
- `project/ps_insar_cumulative_displacement_batch.qgz`：可编辑多布局工程；
- `maps/png`和`maps/pdf`：逐时相专题图；
- `qa`：总报告、每期PASS记录和任务状态。

取消会在当前批次结束后生效，并保留取消状态及临时工作文件；当前不支持
在原run中断点续算，重新执行会创建新的run。

## 8. PS-InSAR 多点形变时序回查

输入包括一个符合插件结构的多时相GeoPackage和一个点位CSV。GeoPackage应包含
`ps_timeseries_points`和`time_catalog`；点位CSV至少包含`ps_uid`。

1. 选择多时相GeoPackage、点位CSV和已存在的输出根目录；
2. 点击“只读检查输入”，确认点数、时相日期范围和单位mm；
3. 已含`selection_rank`的清单会按原顺序回查；完整候选表会按默认四层各
   12点、全局最小间距500米自动抽样；
4. 选择CSV、点位GeoPackage、总览PNG和明细PDF；
5. 点击“检查当前设置”后运行；完成后可自动加载48点结果并缩放。

对于完整候选表，默认48点为A/B×LOW/HIGH的均衡受控样本，C类不进入默认样本。输出分为
`01_数据表`、`02_点位图层`、`03_图表`和`04_质量报告`。形变量单位为mm，
正值向上、负值向下。曲线及统计量只支持人工回查，不等于自动异常判定，
也不直接给出物理成因结论。单次最多200点，以防明细PDF失控。

## 9. 输出问题排查

- 地图空白：检查输入CRS、图层范围和当前工程CRS；
- SAR结果全黑：确认输入是否真为线性功率以及显示范围是否合理；
- 文字越界：缩短文字或根据右侧预览减少行数；
- QGZ资源丢失：保持整个run目录结构，不要只移动QGZ；
- 任务失败：保留run及日志，不要直接删除，先查看失败报告。
